# Nivaara | Tech That Cares. Dil Se.

An Apple-inspired minimalist landing page for **Nivaara** - a senior-friendly smartwatch that combines senior independence with family reassurance through thoughtful technology.

## Features
- **High-Contrast & Large UI:** Glanceable typography designed for effortless readability.
- **Emergency SOS & Fall Detection:** Instant connectivity when it matters most.
- **Smart Medication Reminders:** Calibrated haptic cues to keep daily routines on track.
- **Continuous Health Sync:** Real-time background vitals tracking for family peace of mind.

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- Hosted on GitHub Pages / Vercel
